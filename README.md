# Lab 06 - Simple Contacts

**Platform:** React Native (Expo + TypeScript)

This app provides a persistent local contact list with:

- Create, edit, and delete contacts
- Search and alphabetical sort controls
- AsyncStorage persistence
- Photo-library selection for each contact
- Jest tests for the pure filtering and sorting logic

## Run

```bash
npm install
npm run ios
npm test
```
